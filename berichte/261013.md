## Set up Kurzerklärt
1) Kopiere z.B. die gewünschte VMware inform einer Zipdatei von einem USB-Stick auf deinen Rechner.
2) Öffne VMware Workstation und klicke auf >> Open a Virtual Machine <<.
3) Wähle die gewünschte Virtuelle Maschine.
4) Öffne die Virtuelle Maschine und Gib Nutzer und Passwort, die angegeben sind, ein.
5) Öffne das Terminal und gib folgenden Befehl ein, um das Tastatur layout auf Deutsch zu setzen:
---
 In Linux:
 ```sh
setxkbmap de
```
In Metasploitable:
```sh
sudo loadkeys de
```
---
6) Now you're ready to work b(0_0).

## VS-Code bekommen Kurzerklärt
1) Gib im Terminal folgenden Befehl ein um VS-Code zu bekommen:
```sh
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
```
2) Überprüfe ob du VS-Code hast und welche version mit:
```sh
code --version
```
3) Öffne VS-Code mit:
```sh
code .
```
4) Now you can work in VS-Code b(0_0).

### Oh, you also want to know how to link it with Git, you could have told me so earlier, but don't worry I've got the perfect guide for you (0_0)
1) Gehe auf das Git Symbol und melde dich mit deinem Git-Account an.
2) Öffne das VS-Code Terminal und gib folgende Befehle ein:
```sh
git config --global user.name "Your Name"
git config --global user.email "Your.Email@Example.something"
```
3) Gib nach jedem Commitment im Terminal folgenden Befehl ein:
```sh
git fetch
```

## Ein kleiner Bonustip
To safly shut down your vm you should allways type following command in the terminal:
```sh
sudo shutdown -h now
```
### You want another special extra tip? Really? Fine whatever, here it comes:
If you want to know what ip you have type the following command, it will show your ip and much more:
```sh
ifconfig eth0
```
